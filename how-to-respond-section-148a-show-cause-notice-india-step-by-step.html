How to Respond to Section 148A Show-Cause Notice Step-by-Step, 7-day window action plan.

/ Day 1-2: Immediate acknowledgement + preservation

First actions.

  1. Acknowledge the notice via Income Tax portal (confirms receipt).
  2. Note exact response deadline (specified in notice; typically 7-30 days from service).
  3. Preserve all records relevant to the AY in question: ITR filed + supporting documents + Form 26AS (Form 168 from tax year 2026-27) + AIS/TIS + bank statements + agreements + property documents + specific transaction evidence.
  4. Request complete 'information' AO has relied on - via RTI if not fully disclosed in notice.
  5. Engage CA / tax counsel immediately - 7-30 days is tight.

/ Day 3-5: Information analysis + classification

What AO alleges.

  • Analyse specific 'information': is it SFT (Form 61A) data, AIS/TIS mismatch, international exchange, specific search output, informant report?
  • Classify: mechanical notice (easy to quash) or substantive issue (needs defence).
  • Legal grounds assessment:
  •   — Jurisdictional: 4-year vs 10-year limit, Section 148A procedure defects.
  •   — Substantive: income was already disclosed, SFT misreporting, duplicate counting, non-taxable receipt (gift, inheritance, exempt).
  •   — Treaty: DTAA relief available, foreign tax credit, treaty-residence tie-breaker.

/ Day 5-7: Response drafting + supporting evidence

Build the case.

  • Documentary refutation of each AO allegation: ITR extract + Schedule showing disclosed income + Form 26AS reconciliation + specific receipts.
  • Legal grounds: cite specific case law + statutory provisions.
  • Section 148A procedure defects: no proper 'information' + mechanical satisfaction + specific procedural deficiencies.
  • Mitigating circumstances: good faith, voluntary disclosure history, no concealment intent.
  • Attach: ITR copies, Form 26AS, bank statements, agreements, specific exhibits.

/ Day 7-30: Response submission + follow-up

Execution.

  1. File Section 148A(b) response on Indian Income Tax e-filing portal before deadline.
  2. Separate request for extension if additional time needed (specific reasoning).
  3. Request personal hearing if specific facts require oral representation.
  4. Follow-up for Section 148A(d) order (AO decides whether to proceed).
  5. If AO drops: documented closure of proceeding.
  6. If AO proceeds to Section 148: formal reassessment notice follows + 30-day return filing requirement.

/ If Section 148 formal notice follows

The full reassessment path.

  • File return within time specified (typically 30 days). Can be same ITR or revised based on position.
  • Reassessment under Section 147: AO proceeds like Section 143(3) scrutiny - document calls + personal hearing + additions proposed + order.
  • Section 147 order appealable to CIT(A) within 30 days.
  • Section 270A penalty: 50% under-reporting / 200% misreporting. Classification is key battle.
  • Writ in High Court: if Section 148A procedure fundamentally defective.

FAQ

Common questions, answered.

What's the Section 148A response window?
7-30 days from service of notice (specific days specified in notice). Can request extension on specific reasoning. Critical window - no response = AO proceeds to 148A(d) order with only AO's version considered.
Can I quash Section 148A notice?
Yes - via Section 148A(b) response (dismissed at 148A(d) stage) OR via writ in High Court if procedure fundamentally defective. Several High Court rulings have struck down defective 148A proceedings. For substantive but weak notices, response alone can achieve dismissal without court.
What's the penalty if Section 148 reassessment confirms addition?
Section 270A: 50% penalty for under-reporting (good faith) or 200% penalty for misreporting (fraud/wilful concealment). Classification is key battle. Section 270AA voluntary disclosure provision can avoid 200%. CIT(A) + ITAT appeal paths available.
What's the limitation for Section 148 reassessment?
Standard: 4 years from end of relevant AY. For AY 2019-20: closes 31 March 2027. Extended 10 years: for escaped income > INR 50 lakh in asset form (immovable property, financial asset, bullion). Current 10-year window: AY 2016-17 to 2018-19 open till specific dates.
